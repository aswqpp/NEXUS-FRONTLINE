### 테스트 결과

- `npm test`: 8개 전부 통과. 같은 입력 2회 실행 해시 일치, 150초 지점 입력 기록 재생 해시 일치, 데이터 오류가 `data/units/sentinel.json:13 base.range`처럼 줄 번호로 나옴.
- `tests/touch.mjs`: 14개 전부 통과 — 드래그 배치, 설치 불가 지점 취소, 레일로 되돌려 취소, 탭 배치 + 확인 버튼, 탭 선택, 판매 확정(3초), 같은 웨이브 전액 환급, 핀치 0.94→2.00, 한 손가락 이동, 일시정지·재개, **10웨이브 터치 완주(승리)**, 승리 문구, 페이지 오류 0.
- `npm run sim` (1~10웨이브, 업그레이드 없음): 균형 클리어 코어 99, 서포터 없음 클리어 100, 몰빵 클리어 82, 무작위 클리어 78. 10웨이브 전체 시뮬레이션 40~100ms.
- 강조색 면적: 배치 중 0.25%, 유닛 선택(범위 채움 포함) 2.27%, 결과 0.07%.
- 스크린샷: `shots/phase2-battle-placement.png`, `phase2-battle-selection.png`, `phase2-result.png`.

### 구현하지 못한 것과 알려진 문제

- **밸런스**: 1~10웨이브는 몰빵·무작위도 클리어한다. 19장 기준(몰빵·무작위 실패)은 Phase 3에서 보호막·은폐·분열이 몰리는 11~20웨이브, 업그레이드, 경제 빌드가 들어온 뒤 다시 맞춘다. 지금 상태로는 판정하지 않았다.
- 업그레이드·진화, RAIL-X 외 3종의 경로, OVERCLOCK·REACTOR, KESTREL, 에너지, 보스 패턴, 이야기(무전·방송·브리핑), 사운드, 저장·이어하기 UI, 길게 누르기 상세, 부팅·메뉴·브리핑 화면은 Phase 3.
- 유닛·적은 단순 도형이다. Phase 1의 벡터 그림(SENTINEL)은 Phase 3에서 아틀라스로 구워 넣는다.
- 하단 선택 패널(200pt)이 열리면 맵 아래쪽(코어 근처)을 가린다. 선택한 유닛이 가려질 때 카메라를 살짝 올리는 처리를 Phase 3에서 검토.
- 성능 목표(적 300·유닛 60·발사체 800에서 60FPS)와 `?stress=1`은 Phase 3. 현재 적 탐색은 전수 순회.
- 실기기 확인 항목은 `docs/playtest.md`.

## 밸런스 1차 (2026-11-27)

판단 깊이 검증을 먼저 했다. 상세는 `docs/balance.md`.

- 변경: RAIL-X 사거리 7→5·피해 18→14, ARC 연쇄 감쇠 0.85→0.70. 웨이브·크레딧은 그대로.

## Phase 3 진행 중 (2026-11-27)

### 끝난 것: 업그레이드 시스템 + SENTINEL 3경로 × 6단계

- 데이터: 효과 연산(mul / add / set / aura / ability), 경로 규칙 검사(경로당 6단계, 수치 단계 ≤2), 종류 분류.
- 시뮬레이션: 경로 규칙(2개까지, 주력 하나, Tier 6 "설계 데이터 없음" — 3장 이전, 맵에 하나), 단계 효과 적용, 강화 중첩(100/60/30%, 공속 +80% 상한), 쌍열, 집중 사격, 표식(받는 피해·은폐 해제·전파), 점착탄, 지휘 노드, 탐지 공유. Tier 6 능력은 데이터만(능력 시스템과 함께 구현).
- 화면: 하단 패널 가운데에 A·B·C 다음 단계(단계 표시, 이름, 가격, 효과 한 줄, 잠김 이유), 구매 가능은 라임 막대 + 가격, 300ms 재입력 무시. 왼쪽에 Tier, 실제 적용 수치, 받는 강화(출처와 적용 비율). 외형은 단순 도형으로 A3·A5·B3·C3 실루엣 변화.
- 밸런스: 단계 가치 측정 도구(`npm run step-value`)로 초안 수치가 유닛 추가 대비 0.04~0.6배임을 찾고 A 경로를 0.95~1.37로 조정(balance.md 9절). 회귀에 단계 가치 띠 추가.
- 검수: `npm test` 16개, `tests/touch.mjs` 16개(업그레이드 탭 구매 포함), `npm run check:balance` 전부 통과.

### 끝난 것: RAIL-X · ARC 3경로 × 6단계

- 메커니즘: 평행 레일, 관통 증폭, 선 길이, 넉백(첫 적 / 전원), 고체력 보너스, 보호막 벗기기, 장갑 박리(모든 아군), 연쇄 2줄, 역감쇠, 방전 폭발, 누설 전류 + 처치 폭발, 은폐 노출, 처형 구속 + 전기 취약, 전기 다리, 아군 전기 오라, 고가 오라, 에너지(노드·처치·웨이브).
- 측정·조정: balance.md 10절. 화력 단계 0.95~1.62 → 띠 안, 대응 단계는 맥락에서 0.98~3.38.
- 검수: `npm test` 24개, 터치 16개, `check:balance`(단계 띠 20개 포함) 전부 통과.

### 남은 Phase 3 순서


00장 완료 조건 전부, 19장 검수 전부 통과. 순서(한 유닛을 끝까지 만든 뒤 다음으로, 20장):

0. 단계마다 `npm run check:balance`, 새 유닛 경로는 `npm run step-value -- <유닛>`으로 0.8~1.6 띠에 맞춘다.
1. CRYO · OVERCLOCK · REACTOR 경로. 제어·지원은 흐름 측정이 맞지 않으므로 실제 웨이브에서 "넣었을 때 팀 코어·처치가 얼마나 느는가"로 재는 도구부터.
2. 업그레이드 트리 화면(3경로 × 6칸)과 업그레이드 패널 시안 2~3개 비교(20장), 진화 미리보기, 능력 시스템(Tier 6 포함), 에너지 HUD.
2. RAIL-X, ARC, CRYO 경로 전부. OVERCLOCK, REACTOR(에너지, 고출력 모드). 강화 중첩 규칙과 받는 강화 표시.
3. 11~20웨이브, 은폐 탐지, FORGE WARDEN 3단계 + 생산구 + 교란 펄스, 보스 체력 막대.
4. KESTREL(레벨, 능력 2개, 이동).
5. 이야기: data/story/c1.json, 무전 띠, GENESIS 방송 띠, 경고 카드, 작전 기록 열람, 도감(길게 누르기).
6. 화면: 부팅(실제 로드 단계), 메인 메뉴(격납고) 시안 2~3개, 해원 지도, 브리핑 로딩, 전투 HUD 시안 2~3개, 일시정지·설정, 승리·패배·통계.
7. 사운드(Web Audio 합성), 저장(설정·최고 기록·읽은 기록·이어하기 = 입력 기록 재생), PWA·오프라인.
8. 밸런스 시뮬레이션 5종 빌드로 19장 기준 맞추기, `?stress=1` 성능, 19장 체크리스트 전 화면 2회 반복.
