## 2. 플레이테스트 절차 (밸런스 확인용)

목적: 봇이 아니라 사람에게도 "조합이 몰빵보다 낫다", "배치 위치가 결과를 바꾼다"가 성립하는지 본다.

1. 대상: 이 게임을 처음 하는 사람 3명 이상, 타워 디펜스 경험자 2명 이상. 같은 데이터 해시로 진행.
2. 설명 없이 시작한다. 진행자는 말하지 않고, 참가자는 생각을 소리 내어 말한다.
3. 1판: 자유 플레이. 2판: "한 종류만 써 보세요". 3판: 자유 플레이.
4. 매 판 결과 화면에서 "플레이 기록 저장" → 파일 이름에 참가자 번호와 판 번호.
5. `npm run replay -- 기록/*.json`으로 재생 일치 확인 후 표로 모은다.
6. 기록할 것: 첫 3웨이브 안에 배치·웨이브 시작을 스스로 했는가(시간), 2판이 1·3판보다 코어를 덜 지켰는가, 웨이브 사이 생각 시간이 웨이브가 갈수록 늘었는가(판단이 생겼다는 신호), 참가자가 말한 혼란 지점.
7. 기준: 2판(몰빵)의 코어가 1·3판보다 낮은 참가자가 과반이 아니면 `balance.md` 기준을 다시 연다.
